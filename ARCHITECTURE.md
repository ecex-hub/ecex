## 安全架构

### 网络隔离

```
┌─────────────────────────────────────┐
│  前端服务器 (DMZ)                    │
│  - 公网IP: xxx.xxx.xxx.xxx          │
│  - 内网IP: 10.0.0.1                 │
│  - 开放端口: 80, 443                │
└──────────────┬──────────────────────┘
               │
               │ 防火墙规则
               │ 只允许访问后端8080
               │
┌──────────────▼──────────────────────┐
│  后端服务器 (内网)                   │
│  - 内网IP: 10.0.0.2                 │
│  - 开放端口: 8080 (仅内网)          │
│  - MySQL: 3306 (仅容器内)           │
│  - Redis: 6379 (仅容器内)           │
└─────────────────────────────────────┘
```

### 数据安全

1. **传输安全**
   - 前端使用HTTPS (推荐)
   - 后端API使用JWT认证
   - 内网通信使用HTTP (可选VPN加密)

2. **存储安全**
   - 数据库密码环境变量
   - .env文件不提交到Git
   - 定期备份数据

3. **访问控制**
   - 防火墙限制端口
   - MySQL仅容器内访问
   - Redis仅容器内访问
